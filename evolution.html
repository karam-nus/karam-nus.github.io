Evolution

Every guide here gets rebuilt from time to time. Drag the divider to see a version against the one before it — and below each pair, the model, the effort setting and the tokens that went into it.

How the details were collected. Screenshots are rendered from each version’s own source (built from the commit that version ended on) at 1440×900 in the site’s default light theme. Dates, commit counts and line changes come from the repositories’ git history. Model names come from the build session’s log or the commits’ co-author lines; where neither exists, from the author’s notes. Effort is the setting chosen for the build.

Token usage counts every model call in the build session: output is text and code the model wrote; input is everything it read, most of which is re-read context served from the prompt cache. Builds whose sessions were not logged show “not recorded” rather than an estimate.
